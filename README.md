# 🎬 IMDb Movies Dashboard (Excel Project)

## 📖 Project Overview
This project is an IMDb Movies Dashboard created using Microsoft Excel. The dashboard provides insights into movie ratings, genres, release trends, and audience voting patterns through interactive visualizations.

---

## 📌 Key Insights
- Top Rated Movies Analysis
- Genre-wise Performance
- Movie Release Trends
- Rating Distribution
- Audience Voting Analysis
- Popular Movies Overview

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
